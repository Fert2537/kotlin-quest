# Kotlin Quest

Русскоязычный сайт для самостоятельного изучения Kotlin через задания об отеле, кофейне, доставке и игровых персонажах.

## Запуск
Откройте index.html в современном браузере с доступом в интернет либо разместите файлы на статическом хостинге. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Проверка
Встроенный Kotlin Playground JetBrains компилирует решения и запускает JUnit-тесты на внешнем сервере. Перед первым запуском пользователь подтверждает отправку своего кода. Нужен доступ к unpkg.com и сервисам Kotlin Playground. Нет локального выполнения произвольного Kotlin или собственного сервера исполнения. При недоступности сервиса уроки и черновики доступны, но прохождение не засчитывается.
Документация: https://github.com/JetBrains/kotlin-playground

## Обучение и данные
Теория, контракты заданий, три последовательные подсказки без готового решения. Опыт за каждое задание начисляется один раз. Черновики и прогресс хранятся в localStorage этого браузера; экспорт и импорт резервной копии доступны в интерфейсе.
Тесты скрыты от редактора, но доступны в исходниках сайта: это тренажёр для самостоятельной работы, не защищённая экзаменационная система.
Ссылки YouTube открывают поиск русскоязычных материалов по теме; отдельные ролики пока не проверены и не отобраны.

## Структура
- index.html — интерфейс
- styles.css — адаптивная тема
- lessons.js — теория, задания, подсказки, тесты
- app.js — редактор, прогресс, импорт/экспорт

## Проверки и ограничения первой версии
Запуск тестов интерфейсной логики: `node tests.mjs` (Node.js 18+).
В текущей сессии выполнены проверки синтаксиса JavaScript и 12 сценариев логики с имитацией DOM и Kotlin Playground. Они не заменяют браузерную проверку или реальную компиляцию Kotlin. Внешний сервис компиляции и адаптивная вёрстка пока не проверены в браузере.
Видеоматериалы представлены поиском по теме, а не проверенной подборкой отдельных роликов.
Курс охватывает базовый Kotlin, ООП и коллекции; корутины и Android-интерфейсы в эту версию не входят.
